Tech Stack: MongoDB, Express.js, React.js, Node.js

Description: Developed a MERN stack railway assistance chatbot application that allows users to log in/signup and search train-related information through a chatbot interface. Since official railway APIs required paid access, structured mock datasets were created to simulate train schedules, arrivals, departures, and route information.
The chatbot supports both direct query input and menu-driven interactions where users can select numbered options to receive train-related information.

Key Features:
User Authentication System
Chatbot-based Railway Assistance
Mock Train Data Management
Menu-driven Query Handling
Responsive Frontend with React

Responsibilities & Learnings:
Built REST APIs using Node.js and Express.js
Managed MongoDB database schema and queries
Implemented frontend-backend communication
Learned data handling and chatbot workflow implementation
Improved understanding of MERN stack development
